- Install PostgreSQL, MongoDB, RabbitMQ, and Redis, replacing the configurations in the `configs/config.yml` file. Ask Hai for this file. It works with `gitbash` or `wsl`, but it won't run the Makefile using `powershell` or `cmd` in Windows because it's configured for Ubuntu. Run the command `make run-sv` to start the server, then open another window in the terminal to run `make run-csm` to run the consumer to listen for RabbitMQ in tasks like sending emails, notifications, background removal, etc.
