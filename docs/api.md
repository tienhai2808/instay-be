- Go to the backend source code and navigate to the folder `internal/infrastructure/api/http/router`. Find the API you want to call and click on the file. Inside, you'll see the routers and handlers that handle that router. Press Ctrl and click on the handler function. Scroll down to find the `req` variable of that function. When declaring that variable, you'll specify its type right next to the `req` variable. Press Ctrl and click on that struct to see what fields it has and how it requests data to send. You can copy and paste the code to ask AI for clarification and validate it in the FE.
